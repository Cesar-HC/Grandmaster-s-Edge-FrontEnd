Acerca de mí

César Ángel Huerta Cárcamo Ingeniería de Sistemas de Información (UPC)

¡Buenas! Soy César Ángel Huerta Cárcamo, estudiante de Ingeniería de Sistemas de Información en la Universidad Peruana de Ciencias Aplicadas (UPC) y me encuentro en el décimo superior de mi respectiva carrera.
Mi enfoque actual incluye el desarrollo web, tanto Backend como Frontend, así como la gestión de análisis de datos con Dashboards. Me gusta innovar al implementar soluciones tecnológicas, además de liderar y organizar el trabajo en equipo dentro de los proyectos.
Domino la gestión de bases de datos en SQL (PostgreSQL, SQL Server) y NoSQL (MongoDB).
Tengo conocimiento en programación C#, C++, Python, desarrollo Backend con Java (Spring Boot), y Frontend con Angular (HTML, CSS y TypeScript). Además, manejo herramientas de análisis de datos como Microsoft Excel y herramientas de BI como: Microsoft Power Bi, Google Data Studio y Tableau.
Actualmente, me encuentro interesado en oportunidades de prácticas preprofesionales y proyectos relacionados con desarrollo de software y análisis de datos mediante Dashboards, donde pueda seguir fortaleciendo mis habilidades y adquirir experiencia en un entorno profesional.
